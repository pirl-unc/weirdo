# Experimental and Ad-Hoc Scripts

Standalone research, evaluation, scoring, and remote-training scripts that are not imported by tests, CI, or the `weirdo` package. Active operational, release, documentation-referenced, cohort-builder, and test-covered scripts remain in `scripts/`.

Run any script from the repository root, for example:

```bash
python scripts/experiments/evaluate_fixed_pmhc_weirdo_combination.py --help
```
